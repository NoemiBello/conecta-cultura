# Conecta Cultura

Proyecto incremental de la asignatura Desarrollo FullStack II.

## Primera etapa
- Estructura HTML inicial.
- Hoja de estilos externa.
- Archivo JavaScript enlazado.

## Ejecución
Abrir `index.html` en el navegador o utilizar Live Server.

.DS_Store
Thumbs.db
.vscode/
node_modules/
